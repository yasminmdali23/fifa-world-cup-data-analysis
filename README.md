# ⚽ FIFA World Cup Historical Data Analysis (1930–2014)

An interactive Power BI dashboard analyzing historical trends, team performance, match outcomes, and attendance across decades of FIFA World Cup tournaments.

---

## 📌 Key Highlights & Features
* **Data Visualization:** Multi-chart layouts summarizing complex historical tournament metrics.
* **Trend Analysis:** Bar charts and geospatial maps tracking total goals, team qualifications, and host nation frequency over time.
* **Interactive Dashboard:** Dynamic filters and drill-downs for exploring individual team performance.
* **Data Storytelling:** Summarizing decades of international sporting data into digestible insights.

---

## 🛠️ Built With
* **Tool:** Microsoft Power BI
* **Data:** Historical FIFA World Cup Datasets (1930–2014)
